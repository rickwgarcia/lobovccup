# Lobo VC Cup — Brand Guidelines

---


## 1. Color palette

### Primary
| Name | Hex | Usage |
|---|---|---|
| **Turquoise** | `#007A86` | Primary brand color. |
| **Ink (Black)** | `#000000` | Body text, card borders, hard-shadow accents. |
| **White** | `#FFFFFF` | Base page background. |

### Neutrals
| Name | Hex | Usage |
|---|---|---|
| **Brand Gray** | `#63666A` |
| **Brand Silver** | `#A7A8AA` | 

### Track accent colors
| Name | Hex | Track |
|---|---|---|
| **Track Startup (Orange)** | `#ED8B00` | Startup Track |
| **Track VC (Olive)** | `#A8AA19` | VC Track |

Don't switch to white text on brand colors; the brand's contrast convention is colored-chip + black text, not colored-chip + white text.

---

## 2. Typography

**Space Grotesk** is the font of choice. 

| Style | Size | Line-height | Weight |
|---|---|---|---|
| H1 | 44px | 1.15 | 500 (Medium) |
| H2 | 30px | 1.15 | 500 (Medium) |
| H3 | 23px | 1.2 | 500 (Medium) |
| H4 | 18px (16px mobile) | 1.4 | 500 (Medium) |
| Body | 16px | 1.55 | 400 (Regular) |
